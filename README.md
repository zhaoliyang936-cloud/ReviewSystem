# ReviewSystem

基于知识点掌握度的“数据结构”个性化复习系统。

开发按里程碑推进，当前已完成 M01 工程基础、M02 身份与权限、M03 知识点与四类题库、M04 普通练习与判分、M05 证据与掌握度、M06 推荐与解释，均经本机验证（M01 第二台机器待验收）；M07 复习任务与反馈、M08 资料检索、M09 错题本、M10 AI 辅导仍为设计阶段。需求与技术方案为 V0.5，见 [需求分析文档](docs/需求分析文档.md) 和 [技术设计文档](docs/技术设计文档.md)。

本分支只维护需求与技术方案文档；各里程碑的代码与验证记录见分支 `M02`—`m06`。
