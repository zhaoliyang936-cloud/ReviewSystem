新增集成测试还覆盖：用户名长度、字符及注入样例；密码 11、12、72、73 字节及中文 UTF-8 边界；角色字段不同值；重复账号；BCrypt 盐值差异与密码验证；服务端存储会话 SHA-256 摘要；不同用户和多个会话的隔离；伪造、过期、退出和禁用后的会话；管理员禁止禁用管理员；实际 CSRF token 绑定会话；按直接 IP 限速与不同 IP；正确和错误凭据。

## 发现的问题

1. 使用真实 HTTP，经 Vite 代理访问时，缺少 CSRF 的匿名注册返回 **401**，预期为 **403**；学生请求管理员禁用接口也返回 **401**，预期为 **403**。两次请求均被拒绝，没有成功执行越权操作；MockMvc 中对应场景返回 403。需要进一步定位真实 Servlet 错误分发与安全过滤链的差异并修复状态码。不能仅凭此测试认定所有权限场景安全。
2. 合法 CSRF 令牌下，注册接口接收格式错误的 JSON（`{`）或 JSON `null` 时返回 **500**，预期应为 **400**。客户端输入错误被记录为服务器错误，需调整异常处理。
