## 8. 遗留与边界

1. **`POST /api/wrong-questions/{id}/variant` 未登录行为与归属校验边界**：`SecurityConfig` 配置为 `.anyRequest().authenticated()`，未登录请求会先被 Security 拦截返回 401，不会进入控制器方法体；当前 `variant` 方法未读取 `Authentication`、未做错题归属校验，因此任意已登录用户对他人错题 id 调用也会返回 501（不泄露任何数据）。M09 不改；M10 实现变式生成时必须补 `Authentication` 与归属 404 校验。
2. **`submit` 并发与首写竞态边界**：`PracticeService.submit` 与 `ReviewTaskService.submit` 均无用户级 advisory lock（advisory lock 在两者的 `create` 方法中）。首写竞态实际已被 `uq_rs_activity_active`（同一学生同一时刻最多一个未完成活动）与 `submit` 对活动行加 `FOR UPDATE` 锁挡住；`WrongQuestionRecorder` 在 `passed=false` 分支改用 `INSERT ... ON CONFLICT (user_id, question_id) DO UPDATE` 属于防御性加固，而非修复线上缺陷。
3. **`rs_question_feedback` 唯一键**：当前唯一键为 `(wrong_question_id, user_id)` 而非 `(question_id, user_id)`（本次不动迁移，如需调整须走 V14+）。
4. **兼容构造器**：`PracticeService` 与 `ReviewTaskService` 保留旧构造器，仅用于兼容既有测试直调构造。
