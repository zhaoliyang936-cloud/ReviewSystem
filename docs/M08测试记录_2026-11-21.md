## 3. 验收标准逐条对应（AC-25、AC-34）

| 验收项 | 覆盖测试与实现 | 结果 |
|---|---|---|
| **AC-25**：未发布、其他知识点/课程或未授权资料不进入检索 | `MaterialSearchTest.draftNotSearchablePublishedSearchableAndWithdrawnImmediatelyExcluded`（DRAFT/WITHDRAWN/其他知识点均返回空）；`MaterialIntegrationTest.studentAndAnonymousAccessAreDenied`（未登录 401、学生访问 `/api/admin/materials*` 全部 403）；`MaterialSearchService` 固定限定 `subject_id = 1 AND publication_status = 'PUBLISHED'` | 通过 |
| **AC-25**：排序与截断规则 | `MaterialSearchTest.rankingByHitCountDescThenChunkIdAscAndCappedAtThree`（命中数降序 + 同分 `chunk_id` 升序，最多 3 段）；`emptyQueryFiltersByKnowledgePointOnlyAndTokenizationIsCaseInsensitive`（中文 ≥2 字二元组、英文完整词、大小写不敏感、空 query 仅知识点过滤） | 通过 |
| **AC-34**：版本不可变、撤回后不可复用 | `MaterialIntegrationTest.editingLeavesOldVersionImmutableAndRejectsVersionConflicts`（编辑生成 v2，v1 行不可变，旧 `expectedVersion` 报 409 `STATE_CONFLICT`，`(material_id, version)` 唯一键拒绝冲突）；`MaterialIntegrationTest.draftPublishSplitAndWithdrawLifecycle`（拆段 `position` 0..n-1 连续、每段 1–1000 字符、缺失 `sourceLabel` 或禁用知识点返回 400） | 通过 |
| **AC-34**：离线导入全量校验、幂等与整批回滚 | `MaterialImportTest.idempotentMaterialAndAssetQuestionImport`（题图 SHA-256 校验、同键同内容第二次全部 `skipped`、同键不同内容报冲突且不覆盖已发布版本）；`MaterialImportTest.failedBatchRollsBackAllWritesLeavingCountsUnchanged`（坏批次回滚后 `rs_question` / `rs_question_asset` / `rs_material_version` / `rs_material_chunk` 计数零变化） | 通过 |
