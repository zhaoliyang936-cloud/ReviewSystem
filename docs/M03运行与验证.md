# M03 运行与验证

本文补充 M03“单课程、知识点与四类题库”的迁移、配置、启动、导入和验证方式。基础依赖、数据库创建及 M01/M02 身份初始化方式分别见 `M01启动与验证.md`、`M02身份与权限.md`。

## 数据库迁移

后端启动时由 Flyway 按顺序执行 `backend/src/main/resources/db/migration/` 中尚未应用的迁移：

- `V3__course_and_question_bank.sql`：创建固定课程、章节、知识点、题目、不可变题目版本、题图和导入幂等台账，以及稳定题号序列；写入“数据结构”课程与章节/知识点种子，不写题目种子。
- `V4__question_generation_trace.sql`：为 `rs_question` 增加可空的 `origin_question_version_id`、`gen_job_id` 及索引，预留 M10 生成回链；不包含 AI 调用。
- `V5__chapter_optimistic_lock.sql`：为章节增加 `version` 乐观锁列；管理端更新章节必须提交 `expectedVersion`，旧版本返回 409 `STATE_CONFLICT`。

不要修改已经执行的 V1—V5。后续变更必须新增前向迁移。启动后可只读检查：

```sql
SELECT installed_rank, version, description, success
FROM flyway_schema_history
ORDER BY installed_rank;
```

## 环境变量与题图目录

在启动后端的 PowerShell 窗口设置数据库和题图目录：

```powershell
$env:DB_URL = 'jdbc:postgresql://localhost:5432/reviewsystem'
$env:DB_USER = 'reviewsystem'
$env:DB_PASSWORD = Read-Host '数据库密码'
$env:QUESTION_ASSET_DIR = 'D:\ReviewSystemData\question-assets'
$env:AI_ENABLED = 'false'
```

`QUESTION_ASSET_DIR` 必须指向 Web 根目录之外、后端进程可读写的持久目录。未设置时使用 `${user.home}/.reviewsystem/question-assets`。题图只允许实际可解码的 PNG/JPEG，每张最多 5 MB，每个题目版本最多 5 张；Spring multipart 配置为单文件 5 MB、单请求 6 MB。

## 启动与管理入口

分别启动后端和前端：

```powershell
cd backend
mvn spring-boot:run
```

```powershell
cd frontend
npm ci
npm run dev -- --host 127.0.0.1 --strictPort
```

默认前端地址为 `http://127.0.0.1:5173/`，后端为 `http://localhost:8080/`。管理员登录后访问：

- `/admin`：管理端入口，默认进入知识点页。
- `/admin/knowledge`：章节与知识点维护。
- `/admin/questions`：四类题库、章节/知识点/来源/题型/关键词筛选。
- `/admin/questions/new`：人工录题。
- `/admin/coverage`：覆盖统计，分开显示完全无题与有题但全部不可用。

## 离线题库导入

示例 manifest 位于 `backend/scripts/question-manifest.example.json`。复制后填写真实知识点 ID、来源标签、来源题号和四类题结构；manifest 不得提供 `origin`，导入题固定为 `MANUAL`。

在 `backend/` 目录执行：

```powershell
.\scripts\import-questions.ps1 `
  -Manifest .\scripts\question-manifest.example.json `
  -Report .\import-report.json
```

脚本沿用当前窗口的 `DB_URL`、`DB_USER`、`DB_PASSWORD`。它先校验整份 manifest，再逐条写入；幂等键为“来源标签 + 来源题号 + 题型”。部分条目失败时其他合法条目仍可写入，报告写入指定 JSON，进程退出码为 1；完全成功或全部跳过时退出码为 0。

## 已知限制

- 系统固定只有 `id=1` 的“数据结构”课程，不提供课程新增或删除接口。
- 编辑题目会创建不可变新版本，并把题图复制为新随机存储键；历史版本附件可单独删除，当前版本附件不可删除。
- 管理创建和离线导入接口不能提交或伪造 `AI_GENERATED`；M03 只保留来源字段与分列统计，真实 AI 生成属于 M10。
- `GET /api/questions/{id}` 是为 M04 预置的只读学生 DTO，目前只检查题目为 ACTIVE，不含练习、任务或用户归属语义。
- M03 不包含组卷、作答、判分、题目快照、证据、掌握度、错题、资料或 AI 调用。
